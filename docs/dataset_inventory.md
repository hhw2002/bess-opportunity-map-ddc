# Dataset inventory

Human-readable companion to `config/datasets.yaml` (which is authoritative for paths, mappings
and metadata) and `data/manifests/` (exact checksums). Update when a dataset is added, verified
or refreshed.

**Verification status:** `verified` (official page, publication date and licence checked) ·
`to_verify` (file in hand, provenance incomplete) · `investigating` (identified, not obtained) ·
`synthetic` (demo only).

**Dates:** keep *publication date* (by the provider), *retrieval date* (our download),
*observation period* (what the data describes) and *processing date* (in run records)
distinct. Do not infer currency from an old document's date — check the provider's page.

## Synthetic datasets (demo)

All `demo:` entries in `datasets.yaml` are generated by `bess_catalonia.demo` (seed 42) into
`data/sample/`. They contain deliberate problems (missing values, a duplicate row, duplicate
names, ambiguous / unmatched / broken-crosswalk congestion nodes, invalid coordinates, unknown
statuses, suppressed demand, municipalities without data). Never use them as evidence.
